Try the Web Demo

A simple Flask demo is available under web_demo/ to test ocr_tamil locally. It provides image upload, OCR inference and a download button for extracted text. See web_demo/README_demo.md for steps to run it locally.


## Try the demo (local)
We added a minimal Flask demo in `web_demo/` to test OCR Tamil locally.


Steps:
1. `cd web_demo`
2. `python -m venv .venv && source .venv/bin/activate`
3. `pip install -r requirements.txt`
4. `python app.py` (then visit `http://localhost:5000`)


See `web_demo/README_demo.md` for more details and Docker instructions.
